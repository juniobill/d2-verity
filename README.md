# D2 - Veracidade

Um site para treinar a mecânica do 4º encontro da raid: O Limiar da Salvação do jogo Destiny 2.

Versão **PT-BR** do projeto [D2 Mechanics](https://github.com/rdeleon-dev/rdeleon-dev.github.io).

# Referência das formas

T = Triângulo
C = Círculo
Q = Quadrado

CC = Esfera (Círculo + Círculo)
TT = Pirâmide (Triângulo + Triângulo)
QQ = Cubo (Quadrado + Quadrado)

CT = Cone (Círculo + Triângulo)
CQ = Cilindro (Círculo + Quadrado)
TQ = Prisma (Triângulo + Quadrado)
